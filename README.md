# DSU-Ride-Concept-Demo
Just a small demonstration of an app for our presentation.

**Live app:** https://aakashr-exe.github.io/DSU-Ride-Concept-Demo/. It runs in the browser on any phone, tablet, or laptop, and can be installed to the home screen.

The app lives in [`dsu-ride-demo/`](dsu-ride-demo/). Its [README](dsu-ride-demo/README.md) covers the demo walkthrough, how the code is organised, and how to run and test it locally (`npm start`, `npm test`).
